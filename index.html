ShadowSwitch — Remote Power Management

A lightweight remote-management utility for Windows PCs. A small Go agent (receiver.exe) listens for commands over Firebase (cloud) or directly over the local network, so a machine can be shut down, restarted, locked, or logged out from a web dashboard.

My contribution: Managed the project and created this based on my ideas.

2-Player PVP Arcade — Local Multiplayer Game

A two-player arena battle game built on HTML5 Canvas. Player 1 controls with the mouse (left click to attack); Player 2 uses WASD and the F key. Players fight over health hearts and pick up power-ups — a sword, a shield, speed boots, and bombs.

My contribution: Solo developer
